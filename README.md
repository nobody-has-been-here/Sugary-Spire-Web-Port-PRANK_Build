# Sugary-Spire-Web-Port-PRANK_Build
Instructions on how to play Sugary Spire Web Port P-Rank Build on the web!!

Step 1: Go to code, make a new codespace on main, then in your terminal, copy and paste THIS command (using Ctrl+Shift+V): gh release download hotfix -R burnedpopcorn/Sugary-Spire-Web-Port -p SS_Prank_WebBuild_HOTFIX.zip

Step 2: Wait for the first command to get done, then do this one: unzip SS_Prank_WebBuild_HOTFIX.zip && rm SS_Prank_WebBuild_HOTFIX.zip

Step 3: Wait for that to get done, then do: python3 -m http.server 8080

Step 4: Then open your port (8080) in a Web browser, wait for it to load, click "betterrunner.html" or whatever the html file is called, and it is done!

# For people who have a existing codespace with installed files

Do Step 3 in the main instructions, then do step 4.
